# ParkMinPackages.SQLiteToolkit

Reusable SQLite database and reactive table utilities for Unity projects.

## Installation

```text
https://github.com/ParkMinPackages/SQLite-Toolkit.git
```

## Dependencies

Install the following NuGet packages with NuGetForUnity before using this package:

- `sqlite-net-pcl` `1.11.285`
- `ObservableCollections.R3` `3.3.4`

These packages resolve the following transitive dependencies:

- `SQLitePCLRaw.core` `3.0.3`
- `SQLitePCLRaw.provider.e_sqlite3` `3.0.3`
- `SourceGear.sqlite3` `3.53.3`
- `ObservableCollections` `3.3.4`
- `R3` `1.3.1`

Unity Package Manager does not install NuGet dependencies automatically.
